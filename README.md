# cnation font

구글 한글 폰트를 **용도별로 골라서, 쓸 글자만 담아 내보내는** 도구.
→ https://cnation-font.vercel.app

앱이나 게임을 만들 때마다 폰트를 고르는 일이 번거롭고, 골라도 전체 폰트를
그대로 쓰면 한글은 한 벌에 2MB 가까이 된다. 이 둘을 한 자리에서 끝낸다.

## 무엇을 하나

**1. 용도로 좁힌다** — 본문·리딩 / UI·앱 기본 / 타이틀·헤드라인 / 게임·임팩트 /
코드·숫자 / 손글씨·감성. 여기에 평범↔튐 슬라이더, 굵기 수, 가변폰트 여부를 건다.

**2. 내 문구로 본다** — 미리보기 텍스트에 실제 쓸 문구("레벨 선택", "SCORE 1250")를
넣으면 모든 카드가 그 문구로 렌더된다. 상세 화면에서는 게임 HUD와 앱 다이얼로그
목업에 직접 얹어본다. 카드에서 예뻐 보이던 폰트가 버튼에서 무너지는 일이 잦아서다.

**3. 최적화해서 내보낸다** — 앱에 쓸 텍스트를 통째로 붙여넣으면 그 글자만 담은
woff2 와 바로 쓸 `@font-face` 스니펫이 나온다. 보통 95~99% 줄어든다.

## 분류는 어디서 오나

`google/fonts` 레포의 `tags/all/families.csv` — 구글이 1,941개 패밀리에 사람 손으로
매긴 태그별 0~100 점수다. 이걸 용도 점수로 환산한다. 규칙은 `scripts/classify.mjs`.

설계에서 걸렸던 부분들:

- `/Quality/*`(Spacing·Wordspace·Drawing)는 **제작 품질**이지 본문 가독성이 아니다.
  이걸 가독성으로 쓰면 Black Han Sans(Wordspace 90)가 본문용으로 분류된다.
- `Rugged`·`Futuristic`·`Awkward`는 **질감** 태그다. 자극으로 치면
  Sunflower(Calm 80, Loud 1)가 본문에서 탈락한다. 약한 감점으로만 쓴다.
- 태그 CSV 는 가변폰트를 굵기별로 채점한다. 최댓값을 쓰면 폰트 성격이 제일 굵은
  인스턴스로 왜곡되므로 400 에 가장 가까운 행을 고른다.
- `METADATA.pb` 의 `fonts{}` 는 가변폰트의 기본 인스턴스만 나열한다. `wght` 축을
  펴지 않으면 Noto Sans KR 굵기가 `[400]` 하나로 잡힌다.

자동 분류가 틀린 폰트는 `data/overrides.json` 에서 손으로 바로잡는다.

## 100종을 어떻게 다 보여주나

Google Fonts CSS API 의 `text=` 파라미터가 요청한 글자만 잘라서 내려준다.
거기에 뷰포트에 들어온 카드만, 12개씩 묶어 CSS 한 장으로 받는다.

실측(한글 38종, 1280×900):

| | 전송량 |
|---|---|
| 첫 화면 (15종) | 167 KB |
| 38종 전부 | 508 KB |
| Noto Sans KR 전체 원본 | 1,820 KB (124개 파일) |

한 가지 반직관적인 사실: **한글 서브셋 크기는 글자 수에 비례하지 않는다.**
`다람쥐 헌 쳇바퀴에 타고파`(11자)는 28 KB 인데 `가나다라마바사…`(84자)는 13 KB 다.
복합 모음(쳇·퀴)이 자모 컴포넌트를 더 끌고 오기 때문이다. 미리보기 기본 문구를
바꾼 것만으로 첫 화면이 584 KB 에서 167 KB 로 줄었다.

## 개발

```bash
npm install
npm run fonts     # data/fonts.json 생성 (한글 폰트만)
npm run fonts:all # 전체 1,900여 종
npm run dev
```

`scripts/build-index.mjs` 는 `fonts.google.com/metadata/fonts` 를 1차 소스로 쓰고,
막혀 있으면 `google/fonts` 레포의 `METADATA.pb` 크롤로 폴백한다. 생성된 JSON 을
레포에 커밋하므로 **런타임에는 구글 API 를 호출하지 않는다** — API 키도 쿼터도 없다.
매달 1일 GitHub Actions 가 다시 만들어 변경이 있으면 PR 을 연다.

## 라이선스

앱 코드는 이 레포를 따른다. 폰트는 각자의 라이선스(대부분 OFL)를 따르며,
내보낸 서브셋을 배포할 때는 라이선스 파일을 함께 넣는 것을 권한다.
